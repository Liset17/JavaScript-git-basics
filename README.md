# JavaScript-git-basics

Ejercicios basicos de JavaScript, realizados mientras practico Git y control de versiones.

## Contenido

- `tipos-de-variable.js`, `tipos-de-variable-2.js`: tipos y reglas de nombres de variables.
- `operadores-comparacion.js`, `operadores-logicos.js`: operadores de comparacion y logicos.
- `if-else.js`, `ejercicio-if-else.js`, `ejercicio-if-else-2.js`: condicionales if/else y operador ternario.
- `ejercicio-switch.js`: estructura switch.
- `ciclo-while.js`, `ciclo-for.js`: ciclos while y for.
- `rango-de-valores.js`: validacion de rangos de valores.
- `arreglos.js`, `matriz.js`: arreglos y matrices.
- `funciones.js`, `procedimientos.js`: funciones y procedimientos.
- `paso-por-valor.js`, `paso-por-referencia.js`: diferencias entre paso por valor y por referencia.
- `ejercicio-suma.js`: ejercicio de sumatoria con ciclos.

## Tecnologias

- JavaScript

## Nota

Este repositorio es una practica personal de fundamentos de JavaScript, usada tambien para aprender el flujo basico de Git (commits, historial y organizacion de archivos).
